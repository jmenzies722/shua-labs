# Shua Labs

**Ten specialists. One founder. No product yet.**

Public lab surface for [Shua Labs](https://github.com/jmenzies722/shua-labs) — Josh Menzies' New York lab. An AI specialist org run from a GitHub constitution. Building in the open. No invented traction.

Live: [shua-labs.vercel.app](https://shua-labs.vercel.app)

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- Deployed on Vercel

## Develop

```bash
npm install
npm run dev      # http://localhost:3000
npm test
npm run build
```

## Editing content

- `data/site.ts` — hero copy, specialists, lab log, social handles, episode drafts
- Routes: `/` `/watch` `/lab` `/system` `/thesis` `/registry`

Social channels stay `live: false` until the founder actually opens YouTube and Instagram. Do not link 404s. Do not invent follower counts.

## Honesty

This site does not claim customers, revenue, or a launched product. Empty lab log entries are valid. Company OS internals stay private (`jmenzies722/company-os`).
